# Start with Glassify

Run Glassify.exe from the installed or fully extracted folder.

1. Open Global and enable Global transparency.
2. Choose focused/background opacity and click Apply opacity. Lower values are more transparent.
3. For per-app settings, turn Global off, select a window in Windows and Save for app.
4. Ctrl+Alt+scroll adjusts the window under your pointer.

Focus > Minimize other windows is optional and off by default. Ctrl+Alt+F toggles it and restores its minimized windows when switched off.

Settings contains color themes, Minimal/Glass styles and tray behavior. Instant reopen keeps the interface ready. Low memory releases it after hiding.

The close/minimize buttons normally hide Glassify to the tray. Double-click its icon to reopen it. Quit and restore stops the app and restores managed windows.

Keep GlassifyRecovery.exe, WebView2Loader.dll and the web folder beside Glassify.exe. See docs/INSTALLATION.md and docs/USER-GUIDE.md for details.
