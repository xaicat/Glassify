# Changelog

## 1.0.0 - Initial release

- Global and per-app window transparency with separate focused/background opacity.
- Temporary window overrides, twelve presets and adjustable color tints.
- Pointer-wheel opacity control and keyboard shortcuts.
- Optional Focus mode with settling delay, display scope, exclusions and restoration.
- Background-only taskbar opacity with a one-time optional engine setup.
- Light, VS Code, Midnight and Ember color themes; Minimal and Glass interface styles.
- Compact controls, visible keyboard focus and responsive layouts.
- Instant tray reopening, optional Low memory mode, startup preference and settings import/export.
- Recovery helper for owned opacity changes, minimized placements and the managed taskbar process.
- Portable ZIP and per-user installer for Windows x64, with SHA-256 checksums.
