# Roadmap

Planned work is not part of the current feature set.

- Broader Windows 10/11, multi-monitor and GPU compatibility coverage.
- Screen-reader and high-contrast accessibility testing.
- Additional restoration and Explorer-restart tests.
- Lower-memory warm reopening and frame-time measurements under real workloads.
- Signed distribution and a documented release verification process.

Open an issue before implementing changes that alter window ownership, recovery or global defaults.
